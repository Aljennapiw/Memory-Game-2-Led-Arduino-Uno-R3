Ini adalah proyek pertama saya menggunakan Arduino Uno R3 yang bernama Memory Game.
Pada proyek ini saya menggunakan beberapa komponen, yaitu:

Arduino Uno R3
Kabel jumper male-to-male
Kabel jumper male-to-female
Resistor 220Ω
2 LED (merah dan hijau)
Breadboard
Buzzer
Push button

Software yang saya gunakan adalah Arduino IDE.

Cara Bermain

Pemain harus menekan salah satu tombol untuk memulai permainan.
LCD akan menampilkan level dan kecepatan permainan. Setelah itu, LED akan menyala mengikuti pola tertentu. Pemain harus menekan tombol sesuai warna LED yang muncul (tombol kiri untuk warna hijau dan tombol kanan untuk warna merah).

Jika pemain berhasil mengikuti pola dengan benar, permainan akan berlanjut ke level berikutnya dengan kecepatan LED yang semakin cepat. Jika pemain gagal, LCD akan menampilkan tulisan “GAME OVER”. Untuk memainkan game kembali, pemain harus menekan salah satu tombol.

English Version

This is my first project using an Arduino Uno R3 called Memory Game.
In this project, I used the following components:

Arduino Uno R3
Male-to-male jumper wires
Male-to-female jumper wires
220Ω resistor
2 LEDs (red and green)
Breadboard
Buzzer
Push buttons

The software I used is Arduino IDE.

How to Play

The player must press one of the buttons to start the game.
The LCD will display the current level and game speed. After that, the LEDs will light up in a specific sequence. The player must press the button according to the LED color shown (left button for green and right button for red).

If the player successfully follows the sequence, the game will continue to the next level with faster LED speed. If the player fails, the LCD will display “GAME OVER”. To play again, the player needs to press one of the buttons.
